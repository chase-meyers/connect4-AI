# connect4-AI

## Project Structure

*Originated on October 15, 2026, updated on Nov 8 *
```text
├── C4Board.cpp         # Connect Four board implementation

├── main.cpp            # Main program entry point

├── README.md           # Project documentation
└── agent.py            # AI agent playing
```
